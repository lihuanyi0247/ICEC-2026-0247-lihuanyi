# 课题 10：日常数字任务耗时审计与 AI 批处理实证

## 1. 选题

选了一件**我真的每两周要做一次**的事：把手机/微信里导出的照片、截图、作业文件
按「日期_课程_序号」重命名归档。附带测了两件相邻的高频任务作对照：

| 任务 | 说明 | 每次文件数 |
|---|---|---|
| 批量重命名 | 手机照片/截图按规范改名归档 | 12 |
| 表格汇总 | 多份实验数据 CSV/Excel 合并成一张 | 6 |
| 笔记提取 | 截图里的板书/笔记转成文字 | 8 |

每个任务测 **3~4 个样本**（不同日期、不同内容），共 10 个样本：

| 任务 | 轮数 | 每轮文件数 | 小计 |
|---|---|---|---|
| 批量重命名 | 4 | 12 | 4 |
| 表格汇总 | 3 | 6 | 3 |
| 笔记提取 | 3 | 8 | 3 |
| | | | **10** |

> **10 轮全程用同一批提示词，一字不改** —— 提示词在 `scripts/PROMPTS.md`，照抄。
> 每次换说法，测出来的就是"提示词写得好不好"，不是"这个任务该不该交给 AI"，
> 10 个样本之间也没法比。

## 2. 测量方法（一定要说清，否则数字不可信）

- **人工**：从"打开文件夹"到"确认全部改完"的墙钟时间，手机秒表掐。
  包含所有中断（改错一个要重来）——不许挑最顺的一次。
- **AI**：从"把需求发给 AI"到"拿到可运行脚本/结果"的时间。
- **校验**：拿到结果后，人工逐条核对（或抽查）花的时间。
  **这是 AI 方案最容易被忽略的成本，也是这题的核心**。
- 每个样本记 3 个数：人工耗时、AI 耗时、校验耗时 + 错误数。

> 掐表时请**同一台设备连续测完**，不要分几天测（手速会变）。

## 3. 操作步骤

1. 复制 `raw_data/耗时记录-示例格式.csv` → `raw_data/耗时记录.csv`，**清空示例数字**。
   > ⚠️ 示例文件里的数字是编的，只示范格式，不能作为提交数据。
2. 准备测试素材：真的 12 个待改名文件、6 个表格、8 张截图，放在临时目录。
3. 人工做一遍 → 记时。恢复原状。
4. 用 `batch_rename.py` 做一遍 → 记 AI 耗时 + 校验耗时。

```bash
# 预览（不会动文件）
python batch_rename.py --dir "D:/临时素材" --course 通信原理
# 确认无误后执行
python batch_rename.py --dir "D:/临时素材" --course 通信原理 --apply
```

5. 拍 1 张同框照（电脑屏幕 + 你的手/桌面），放 `../figures/`。

## 4. 出结果

```bash
python analyze_t10.py --dev-min 45      # 45 = 我写/调这个脚本一共花的分钟数，按实际改
```

产出：
- `../figures/T10-耗时对比.png`（左：逐样本耗时对比；右：提速倍数 + 错误率）
- `raw_data/分析结果.csv`
- `T10-结论.md`（含**盈亏平衡点**和**人机校验规则表**，标 ▢ 的补完）

## 5. 这题的得分点在哪（别只写"AI 快 5 倍"）

| 层次 | 写法 | 得分感觉 |
|---|---|---|
| 及格 | "AI 比人工快 5 倍" | 只有结论 |
| 良好 | 分开算 AI 耗时和校验耗时，给出错误率 | 成本意识 |
| **优秀** | **算出盈亏平衡点（重复多少次才值得写脚本）**，并给出"什么任务该全自动、什么必须人看"的规则 | 工程判断 |

## 6. 面试可能追问

| 问题 | 准备方向 |
|---|---|
| 校验时间怎么定的？ | 逐条核对全部输出。如果只抽查，我会说明抽查比例和漏检风险的估算方式。 |
| 为什么不直接每次让 AI 处理，非要写脚本？ | 因为脚本可复现、可留日志、可回滚；AI 对话式处理每次都要重新描述需求，且出错无从追溯。平衡点算出来是 ▢ 次。 |
| AI 出的错是哪一类？ | 结构化任务几乎不出错（改名、格式转换）；语义任务（字迹识别）错误率高且**错误很隐蔽**（错字但语句通顺），所以必须人看。 |
| 如果这个任务只做一次？ | 直接用 AI 对话处理，别写脚本。开发成本摊不回来。 |
