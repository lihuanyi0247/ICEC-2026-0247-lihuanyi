# 关键 AI 提问与排障对话记录

> 考核说明里明确要求：**"关键 AI 提问排障对话记录"**。
> 但要的不是"我问了 AI 一句话、AI 给了我一段代码"——那种记录反而扣分。
>
> 有说服力的记录长这样：**我发现了什么问题 → 我怎么描述给 AI → AI 给的建议哪里不对**
> **→ 我怎么验证并修正 → 最后学到什么**。
>
> 面试官第三阶段会拿这个仓库动态生成追问（"这里你当时为什么换方案？"），
> 所以每一段都要经得起问。

---

## 记录格式（复制这个模板）

```markdown
### 2026-11-XX ｜ 一句话标题：例如「AI 建议的 STFT 参数把低频全丢了」

**背景**：我在做什么，卡在哪。

**我的提问（原文粘贴，不要润色）**：
> （把你发给 DeepSeek/Qwen/Kimi 的完整提示词贴在这里，包括你给的报错和代码片段）

**AI 的答复（关键部分摘录）**：
> （贴 5~15 行，别贴整篇）

**问题：AI 说错的地方 / 没说全的地方**
- （例如：它建议 n_fft=256，但 16kHz 下频率分辨率变成 62.5Hz，
  风扇转频 24Hz 根本分辨不出来）

**我怎么验证的**
- （例如：拿一段已知 24Hz 的录音跑了一遍，谱峰出现在 0 和 62.5 两个 bin 上，
  明显对不上 → 改回 4096）

**最后怎么解决的**
- 最终参数 / 最终写法

**复盘**
- 下次遇到同类问题，我会先 ▢ 再问 AI。
```

## 本项目需要留档的 3 段（建议，可按实际替换）

### 1. 环境搭建 / Git 建仓（Step 0 要求的那条）

提示词建议原文：

> 我是零基础大一新生，Windows 11，Python 3.13。请一步步教我把本地文件夹
> 推送到 GitHub 仓库，遇到报错我发给你排障。

要记的是：**你踩到了什么具体的坑**（大概率会遇到下面几个之一）
- `git: command not found` → 本机根本没装 Git（这台机器就是这种情况，见 `docs/02`）
- `fatal: not a git repository`
- `Updates were rejected because the remote contains work...` → 忘了先 pull
- `error: src refspec main does not match any` → 分支还叫 master

### 2. 音频读取失败（真实会遇到）

现象：`wave.Error: file does not start with RIFF id`，或脚本提示"本机没有 ffmpeg"。
AI 八成会让你 `pip install librosa` —— 但那会拖进来一堆依赖。
你的判断：本项目只需要读 PCM WAV，标准库 `wave` 就够，不引入 librosa。
→ 这段能直接证明"你会否定 AI 的建议"。

### 3. 准确率高得可疑（最有价值的一段）

现象：第一次跑出来 5 折准确率 99.8%，改成留一会话后掉到 88%。
你自己起了疑心，去查"同一段录音切出来的窗口是不是同时进了训练集和测试集"，
于是改成按会话分组（`LeaveOneSessionOut`），数字掉到 88%。
→ 这段是全仓库最能体现**科学素养**的记录，一定要写。

> 提示词参考：
> 「我的 5 分类音频任务，随机 5 折准确率 99.8%，但我只有 75 个录音文件，
> 切成 1 秒窗后有 1425 个样本。这个数字高得不像真的，可能是什么原因？
> 怎么验证有没有数据泄漏？」
