# 关键 AI 提问与排障对话记录

> 考核说明里明确要求这一项：**"关键 AI 提问排障对话记录"**。
>
> 但它要的不是"我问了一句、AI 给了一段代码"——那种记录反而扣分，
> 因为看不出判断力。有说服力的记录必须包含：
> **我发现了什么问题 → 我怎么描述给 AI → AI 给的建议哪里不对 → 我怎么验证并修正 → 复盘。**

面试官会拿这个仓库动态生成追问（"这里你当时为什么换方案？"），
所以每一条都要经得起问。

## 写作格式（后续新增记录照这个写）

每条记录固定六段，缺一段就不算合格记录：

1. **背景** —— 我在做什么，卡在哪
2. **我的提问（原文粘贴，不润色）** —— 包括报错原文和代码片段
3. **AI 说错的地方 / 没说全的地方** —— 必须有。AI 全对的记录没有价值
4. **我怎么验证的** —— 给可执行的命令或代码，不给"我觉得"
5. **最后怎么解决** —— 最终参数 / 最终写法
6. **复盘** —— 下次遇到同类问题，第一步做什么

---

## 一句话原则

**AI 给的是候选方案，不是结论。**
凡是没在本机跑过、没看过输出、没对照过的建议，都不能直接写进代码。
