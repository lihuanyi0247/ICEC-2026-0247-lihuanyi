## 2. 第二阶段：项目三 · 手机声振异常诊断

### 一句话

电风扇快坏的时候，声音会先变。专业声振仪要上千元，而每台手机都有麦克风。
本项目验证：**普通手机麦克风能否把「转得好好的」和「快要坏了的」分开。**

### 5 种工况与物理线索

| 工况 | 代码 | 物理变化 | 预期特征响应 |
|---|---|---|---|
| 正常·低档 | `N1` | — | 基准 |
| 正常·高档 | `N2` | 转速↑ | 叶频↑、总声压↑ |
| 扇叶失衡 | `F1` | 质心偏移 → 每转一次冲击 | 包络调制深度↑、峭度↑、转频边带↑ |
| 进风遮挡 | `O1` | 气流受阻 → 湍流 | 谱质心↑、谱平坦度↑、高频能量↑ |
| 停机基线 | `S0` | 只剩环境噪声 | 能量↓、谱平坦度≈白噪 |

### 关键结果

| 指标 | 数值 |
|---|---|
| 样本量 | 5 工况 × 3 次实验 × 5 段 = **75 个录音 → ▢ 个 1s 窗** |
| 特征维度 | 58 维（时域 7 + 频域 18 + 调制域 8，均含 mean/std） |
| **留一会话 LOSO 窗级准确率** | **▢%** |
| **文件级准确率（多数投票）** | **▢%** |
| macro-F1 | ▢ |
| 临界信噪比（准确率跌破 80%） | 白噪 ▢ dB ／ 粉噪 ▢ dB |
| 盲测文件级准确率 | ▢%（▢/▢，未参与训练） |

> 为什么用「留一会话」而不是随机 5 折：三次实验共享同一房间混响与背景噪声，
> 随机切分会让同一段录音的相邻窗同时出现在训练集和测试集，模型靠「房间指纹」作弊。
> 两个数字都写在 `results/REPORT.md` 里，差距本身就是数据泄漏的量化证据。

## 4. 已知局限（不回避）

1. **单一设备**：只测了一台 ▢，换一台叶片数/转速不同的风扇，叶频整体平移，模型可能失效。
2. **工况是模拟的**：贴配重模拟失衡，与真实轴承磨损的频谱形态不同。
3. **依赖手机摆位**：距离从 30cm 变到 1m，低频衰减明显。
4. **只有 3 个会话**：LOSO 只有 3 折，置信区间较宽。
5. ▢ 自己再补 1~2 条 —— 能主动说出局限，比被问出来强得多。
