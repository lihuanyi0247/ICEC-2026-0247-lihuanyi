## A. 建仓（本机实测：**还没装 Git**）

这台机器当前 `git` 命令不存在（`where git` 为空），所以先解决这个：

### A1. 安装 Git（推荐，5 分钟）

1. 打开 https://git-scm.com/download/win → 下载 64-bit Git for Windows Setup
2. 一路默认下一步（关键项：默认编辑器选 Notepad 即可；`git init` 默认分支名选 **main**）
3. 装完**关掉所有终端窗口再重开**，否则 PATH 不生效
4. 验证：

```bash
git --version          # 应输出 git version 2.x.x
```

### A2. 配身份（只需一次）

```bash
git config --global user.name  "你的拼音名"
git config --global user.email "你的GitHub邮箱"
git config --global core.quotepath false      # 让中文文件名不乱码
```

### A3. 建远程仓库

在 GitHub 网页 → New repository：
- 仓库名：**`ICEC-2026-1234-zhangsan`**（学号后四位 + 姓名拼音，全小写，无下划线）
- 可见性：**Public**（考核要求公开仓库）
- **不要**勾选 "Add a README file"（本地已经有 README，勾了会冲突）

### A4. 首次推送

```bash
cd "C:\Users\Baron\WorkBuddy\实验班\ICEC-2026-0247-lihuanyi"
git init -b main
git add -A
git commit -m "chore: 初始化仓库结构（README / 三阶段目录 / 代码骨架）"
git remote add origin https://github.com/<你的用户名>/ICEC-2026-1234-zhangsan.git
git push -u origin main
```

推送时会要求登录：GitHub 已不接受账号密码，用 **Personal Access Token**（Settings →
Developer settings → Personal access tokens → Tokens(classic) → 勾 `repo`）当密码用。
或者装 GitHub Desktop（图形界面，自带登录和 git）。
