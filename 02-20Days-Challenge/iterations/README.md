## 怎么拿到真实的 diff 记录

```bash
git log --oneline --graph --all          # 时间线
git show <commit> --stat                 # 某次改动的文件清单
git show <commit>                        # 完整 diff
git diff <commit1> <commit2> -- src/     # 两次提交之间的代码差异
```

把 `git show <commit>` 的输出里最关键的那 10~20 行贴进上面每一节。
**不要伪造 commit hash** —— 面试官会直接在你的仓库里 `git show` 对质。
